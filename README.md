# WB Продвижение → Telegram есеп боты

Бот **тек оқиды**: ставканы өзгертпейді, ақша жұмсамайды.

| Қашан | Не жібереді |
|---|---|
| Әр сағат | Бүгінгі жарнама шығыны, тапсырыстар, ДРР, CPO, баланс, ескертулер |
| Күн сайын 09:00 | Кешегі толық есеп: кампания және тауар бойынша қанша ақша кетті, қанша тапсырыс келді |
| Дүйсенбі 09:00 | Өткен аптаның (Дс–Жс) есебі |

Ескертулер:
- 🔴 CPO шектен асты
- 🟠 ақша кетті, бірақ тапсырыс жоқ
- 🟡 баланс аз
- ⏸ кампания тоқтап қалды

## Орнату (≈15 минут)

### 1. Telegram бот
1. Telegram-да **@BotFather** ашып, `/newbot` жазыңыз. Атын беріңіз, ол сізге **токен** береді. Токенді ешкімге көрсетпеңіз.
2. Жаңа ботқа кіріп, **Start** басыңыз.
3. **@userinfobot**-қа жазыңыз, ол сіздің **chat ID**-іңізді береді.

### 2. WB токені (тек оқу)
1. Seller кабинетін ашыңыз: Профиль → Настройки → **Доступ к API** → Создать новый токен.
2. Санаттар: **Продвижение** және **Статистика**.
3. ✅ **«Только на чтение»** белгісін міндетті түрде қойыңыз.
4. Токенді көшіріп алыңыз.

### 3. GitHub
1. github.com сайтында тіркеліңіз. Жаңа репозиторий жасаңыз: **New repository**, атауы `wb-bot`, түрі ✅ **Private**.
2. **Add file → Upload files** басып, архивтегі барлық файлды жүктеңіз. `.github/workflows/report.yml` файлы да кіруі керек.
3. Settings → Secrets and variables → **Actions** → New repository secret. Үшеуін қосыңыз:
   - `WB_TOKEN`: WB токені
   - `TG_TOKEN`: Telegram бот токені
   - `TG_CHAT_ID`: chat ID
4. **Actions** бетінде **WB report** таңдап, **Run workflow** басыңыз. Telegram-ға есеп келсе, бәрі дұрыс істеп тұр.

## Баптау: `config.json`
- `max_cpo`: тауардың шекті CPO-сы (`nmId: сома`). Колонка 280 ₸, пульт 450 ₸.
- `product_names`: тауарлардың есептегі атауы.
- `must_be_active`: тоқтап қалса ескерту берілетін кампаниялар.
- `alert_low_balance`: балансқа қатысты ескерту шегі.
- `daily_hour`: күндік есептің сағаты (Шымкент уақыты).

Жаңа тауар қоссаңыз, оны `max_cpo` пен `product_names` ішіне жазыңыз.

## Білу керек
- GitHub-тың тегін лимиті жабық репозиторийге айына 2 000 минут. Бот айына шамамен 750 минут жұмсайды.
- Репозиторийде 60 күн бойы ешбір өзгеріс болмаса, GitHub кестені тоқтатады. Ондай болса, Actions бетінде қайта қосу батырмасы шығады.
- Сағаттық есеп кейде 5–15 минут кешігуі мүмкін.

# 🎯 Биддер (bidder.py): кластерлерде 1-орынды ұстау

**Бұл бот ставканы өзгертеді.** Ол сағатына бір рет (:05-те) іске қосылады.

Әр кластерде бот мына тәртіппен жұмыс істейді:
- 1-орында болмасақ, ставканы көтереді. Бәсекелес қай ставкада бізден озғанын есте сақтайды да, содан **1 ₸ жоғары** тұруға тырысады.
- 1-орында тұрсақ, бәсекелестің ставкасына +1 ₸-ге дейін ақырындап түсіреді.
- Ставкаға шек жоқ. Бірақ соңғы 7 күннің **CPO-сы 1000 ₸-ден асса**, бот ставканы көтермейді, Telegram-ға ⚠️ ескерту жібереді.
- Ставка өзгерген сайын Telegram-ға хабар келеді. Өзгеріс болмаса, бот үндемейді.

## Орнату
1. **Жаңа WB токені керек.** Есеп ботының токені тек оқуға арналған, ставканы өзгерте алмайды.
   Профиль → Настройки → Доступ к API → Создать токен → тек **Продвижение** санатын таңдаңыз, **«Только на чтение» белгісін ҚОЙМАҢЫЗ**.
2. GitHub → Settings → Secrets → Actions → New secret: атауы `WB_BID_TOKEN`, мәніне жаңа токенді қойыңыз.

## Алдымен сынақ режимі
`bidder_config.json` ішінде `"dry_run": true` тұр. Бұл режимде бот ештеңе өзгертпейді, тек «не істер едім» деп жазады.
1. Actions → **WB bidder** → Run workflow → `dry` таңдаңыз.
2. Telegram-ға хабар келеді. Ондағы ставкаларды кабинеттегі ставкалармен салыстырыңыз.
3. Ставкалар сәйкес келсе, `"dry_run": false` деп өзгертіңіз. Енді бот шын жұмыс істейді.

## Баптаулар (`bidder_config.json`)
- `clusters`: бот басқаратын кластерлер.
- `max_cpo_tg`: CPO осы сомадан асса, бот ставканы көтермейді (1000 ₸).
- `outbid_tg`: бәсекелестен қанша ₸ жоғары тұру керек (1 ₸).
- `raise_pct` / `raise_min_tg`: бәсекелестің ставкасы белгісіз болғанда қаншаға көтеру керек (5%, кемінде 20 ₸).
- `lower_after_runs`: 1-орында қатарынан неше рет тұрғаннан кейін түсіре бастау керек.
- `bid_units_per_tg`: API бірлігі. Егер сынақта ставкалар 100 есе қате шықса, мұны 1-ге өзгертіңіз.

**Тоқтату керек болса:** Actions → WB bidder → «…» → **Disable workflow**.
