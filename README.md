# WB Продвижение → Telegram есеп боты

Бот **тек оқиды**: ставканы өзгертпейді, ақша жұмсамайды.

| Қашан | Не жібереді |
|---|---|
| Әр сағат | Бүгінгі жарнама шығыны, тапсырыстар, ДРР, CPO, баланс, ескертулер |
| Күн сайын 09:00 | Кешегі толық есеп: кампания және тауар бойынша қанша ақша кетті, қанша тапсырыс келді |
| Дүйсенбі 09:00 | Өткен аптаның (Дс–Жс) есебі |

Ескертулер:
- 🔴 CPO шектен асты
- 🟠 ақша кетті, бірақ тапсырыс жоқ
- 🟡 баланс аз
- ⏸ кампания тоқтап қалды

## Орнату (≈15 минут)

### 1. Telegram бот
1. Telegram-да **@BotFather** ашып, `/newbot` жазыңыз. Атын беріңіз, ол сізге **токен** береді. Токенді ешкімге көрсетпеңіз.
2. Жаңа ботқа кіріп, **Start** басыңыз.
3. **@userinfobot**-қа жазыңыз, ол сіздің **chat ID**-іңізді береді.

### 2. WB токені (тек оқу)
1. Seller кабинетін ашыңыз: Профиль → Настройки → **Доступ к API** → Создать новый токен.
2. Санаттар: **Продвижение** және **Статистика**.
3. ✅ **«Только на чтение»** белгісін міндетті түрде қойыңыз.
4. Токенді көшіріп алыңыз.

### 3. GitHub
1. github.com сайтында тіркеліңіз. Жаңа репозиторий жасаңыз: **New repository**, атауы `wb-bot`, түрі ✅ **Private**.
2. **Add file → Upload files** басып, архивтегі барлық файлды жүктеңіз. `.github/workflows/report.yml` файлы да кіруі керек.
3. Settings → Secrets and variables → **Actions** → New repository secret. Үшеуін қосыңыз:
   - `WB_TOKEN`: WB токені
   - `TG_TOKEN`: Telegram бот токені
   - `TG_CHAT_ID`: chat ID
4. **Actions** бетінде **WB report** таңдап, **Run workflow** басыңыз. Telegram-ға есеп келсе, бәрі дұрыс істеп тұр.

## Баптау: `config.json`
- `max_cpo`: тауардың шекті CPO-сы (`nmId: сома`). Колонка 280 ₸, пульт 450 ₸.
- `product_names`: тауарлардың есептегі атауы.
- `must_be_active`: тоқтап қалса ескерту берілетін кампаниялар.
- `alert_low_balance`: балансқа қатысты ескерту шегі.
- `daily_hour`: күндік есептің сағаты (Шымкент уақыты).

Жаңа тауар қоссаңыз, оны `max_cpo` пен `product_names` ішіне жазыңыз.

## Білу керек
- GitHub-тың тегін лимиті жабық репозиторийге айына 2 000 минут. Бот айына шамамен 750 минут жұмсайды.
- Репозиторийде 60 күн бойы ешбір өзгеріс болмаса, GitHub кестені тоқтатады. Ондай болса, Actions бетінде қайта қосу батырмасы шығады.
- Сағаттық есеп кейде 5–15 минут кешігуі мүмкін.
